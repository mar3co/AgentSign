# Name

**Locked: AgentSign** (one word).

Repo: [mar3co/AgentSign](https://github.com/mar3co/AgentSign).  
Canonical host: **https://agentsign.co**. Alias: **agentsign.net** → 301 to `.co`.  
DNS: Cloudflare, MAR3 Technologies (zones already active).

The product is still a signing primitive (send / sign / fetch). Humans Finish. Agents Attest. “Agent” here means a machine acting for a named human principal, not an insurance/real-estate agent. Paying users can still be a person sending a PDF with no bot involved.
